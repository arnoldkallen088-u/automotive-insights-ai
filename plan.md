# Professional Styling Update - Car Management System

Enhance the visual design of the existing Car Management System to a "Professional Dealership" standard using Tailwind CSS 4 and modern UI/UX principles.

## Style Objectives
- **Sophisticated Palette**: Deep slates, clean whites, and vibrant electric blue accents.
- **Glassmorphism**: Subtle backdrop blurs and transparent layers for a modern, high-tech feel.
- **Premium Cards**: Enhanced shadows, rounded corners (2xl), and smooth hover transitions.
- **Refined Typography**: High-contrast headings and better tracking for a luxury look.
- **Immersive Hero**: A powerful, high-impact showroom entrance.

## Components to Update
1. **index.css**: Add custom utilities for glass effects and smooth gradients.
2. **Navbar**: Glass effect with backdrop blur, refined logo, and better search input.
3. **Sidebar**: Dark mode aesthetic for admin areas, sleek active states.
4. **Showroom**: Improved car grid, high-impact hero section, and better "AI" badge styling.
5. **Login**: Premium, centered auth portal with deep shadows and refined inputs.
6. **Dashboard**: High-contrast stat cards and polished chart containers.
7. **CarList & CarForm**: Modernized data entry and table views with better spacing and contrast.

## Technical Implementation
- Leverage existing OKLCH color variables for consistency.
- Use `framer-motion` for micro-interactions (hover, layout transitions).
- Maintain 100% JavaScript (.jsx) and functional hooks.
